# Сервис чтения файлов конфигурации
На вход ожидается предоставление 3 путей к файлам:
1. .CFG     -   Стандартный файл конфигурации
2. .ON      -   Стандартный файл настройки
3. .ON_S284 -   Сервисный файл настройки. В нем содержатся настройки разработчика (сетевые и прочие). Это нужно для удобства отладки программы

**ConfigReader** является главным классом, выполняющим подготовку необходимых параметров конфигурации
**ConfigParser** является классом, который выполняет непосредственное чтение входных файлов. Он парсит файл, убирая комментарии (все до конца строки после символов "//"), выдавая набор параметров в виде QMap<QString, QStringList>, где ключем является имя параметра, а значением - список значений (может быть одно или несколько)
**ConfigTypes** описывает структуру конфигурационных параметров. Так, все необходимые для программы значения берутся из переменных этой структуры. *В будущем возможно стоит сделать вложенные структуры для лучшей организации этих параметров по тематике использования (сеть, исполнитель директив и т.д.)*
**ConfigShema** описывает требования к входным параметром - обязательные значения, значения по умолчанию.
