# Глоссарий ИСР

ID документов D1–D4 определены в REQUIREMENTS.md (REQUIREMENTS.md#источники). Страницы указаны по порядку в PDF. Имена типов описывают текущий код, термины предметной области взяты из документации.

## Предметная область

| Термин | Значение | Источник |
|---|---|---|
| ИСР | Интерпретатор структур разделов. В руководстве также встречается форма «Интерпретатор структур раздела». | Паспорт, D4 с. 51 |
| ПРИС | Программа проведения испытаний, взаимодействующая с ИСР. | Паспорт, D1 § 1.1, с. 2 |
| ЦПКУ | Центральный персональный компьютер управления. | D4 с. 51 |
| АИС | Автоматизированная испытательная система. | D4 с. 51 |
| СПО | Специальное программное обеспечение. В документации ИСР этим термином обозначаются компоненты и материалы, размещаемые для проведения испытаний. | D2 с. 1–3, D4 с. 51 |
| Сеанс | Уровень работы ПРИС, на котором может начинаться работа до создания раздела. | D1 § 1.2.1, с. 2–3 |
| Раздел | Именованная единица проведения испытаний со структурой и секциями. Может быть головным или вложенным. NoName — обозначение анонимного раздела в описанном режиме ПРИС. | D1 §§ 1.2.1 и 3.6, с. 2–3 и 23–24 |
| Секция | Часть структуры раздела. Документы различают ШТАТ, НШС и ПРИ. Просматриваемая секция может отличаться от секции выполняемой операции. | D1 §§ 1.5.3–1.5.4, с. 9–11 |
| ШТАТ | Секция штатного проведения раздела. | D1 § 1.5.3.1, с. 9 |
| НШС | Нештатная ситуация. В контексте ИСР — секция операций для такого сценария. | D1 § 1.5.3.2, с. 9, D4 с. 51 |
| ПРИ | Секция приведения изделия в исходное состояние. | D1 § 1.5.3.3, с. 9 |
| Директива, операция | В структуре раздела — предусмотренное действие с типом и параметрами. В обмене с ПРИС «директива» также может обозначать внешнюю команду. | D3 §§ 1–7, с. 1–3, D1 §§ 2.2–2.3, с. 17–20 |
| ТФ4 | Формат записи операций структуры раздела с полями номера, типа, текста и действия. | D3 § 1, с. 1 |
| ВАРИАНТ | Директива выбора одного из предусмотренных вариантов выполнения. Границы нумерации требуют согласования. | D2 с. 6, D3 § 3, с. 2 |
| НАЧРАЗД | Директива начала раздела. Допустимые параметры и их синтаксис требуют согласования. | D2 с. 7, D3 § 4, с. 2 |
| ШАГ, АВТ, блок «Авто» | Шаговый и автоматический режимы. Блок «Авто» — отмеченная последовательность операций для автоматического выполнения. | D1 § 1.5.5, с. 13–14, D3 § 4, с. 2 |
| Метка | Именованная позиция в структуре, которую можно указывать как цель перехода. | D4 §§ 3.3.26–3.3.27, с. 19 |
| Трафарет | Настройка оператора, участвующая в подготовке раздела и его заголовка. В материалах упоминается Stencil.dat. | D1 § 1.5.1.2, с. 7, D4 § 3.3.4, с. 13 |
| Протокол испытаний, СП | Протокол фиксирует ход испытаний. «СП» в меню ИСР и обмене относится к сохранению протокола. | D1 § 1.5.4.3 и § 3.6, с. 10 и 23–24 |
| ЭД | Эксплуатационная документация, которую оператор открывает через ИСР. ЭД также встречается как входящая команда ПРИС. | D1 §§ 1.3.8 и 2.3, с. 4 и 20 |
| ПФКС | Внешняя программа, вызываемая из подготовки раздела. Здесь используется обозначение из документации. | D1 §§ 1.2.2 и 1.5.1.3, с. 3 и 7 |
| РЭП | Обозначение роли и соответствующих меню в документации ИСР. Расшифровка и перечень обязательных сценариев требуют подтверждения. | D1 §§ 1.5.7–1.5.8, с. 14–15 |

## Файлы и обмен

| Термин | Значение | Источник |
|---|---|---|
| .cfg | Системный конфигурационный файл, участвующий в настройке запуска и окружения. | D1 § 1.2, с. 2–3 |
| .on | Пользовательский файл настройки с каталогами и перечнем разделов. | D1 § 1.3, с. 3–4 |
| .on_s284 | Сервисный файл настроек, который текущий код принимает по необязательному третьему пути. | Чтение аргументов · README |
| .set | Файл списка разделов либо файл настройки отдельного раздела. Роль определяется местом использования. | D2 с. 3–5 |
| .dii | Файл структуры раздела, содержащий паспорт, секции и директивы. | D2 с. 6–7, D3 с. 1–3 |
| .dip, .prt | Расширения файлов программ испытаний и протоколов, встречающиеся в описании размещения материалов. | D2 с. 1–2 |
| Server | Внешнее приложение, через которое D1 описывает обмен ИСР с ПРИС и канал протокола. | D1 § 2.1, с. 16 |
| Порция, POR, атом | Порция состоит из заголовка POR и атомов. В описании POR `KindofWork` и `SortofWork` обозначают род и сорт работы для адресата, а `AtomType` — тип атома. В таблицах обмена эти три значения приведены вместе. Для некоторых записей указано тело атома. | D1 §§ 2.1–2.3, с. 16–20 |
| ПРОТ | Обозначение протокольного канала в текущем сетевом модуле. | NETManager |
| КТ | Контрольная точка. D1 описывает связанные команды сохранения и восстановления. | D1 § 2.4, с. 21 |

## Термины текущей реализации

| Термин | Значение | Источник |
|---|---|---|
| SectionStruct | Структурированные данные раздела, полученные после разбора .DII. | DiiReader |
| ExecuteFrame | Внутренний кадр исполнителя с разделом, активной главой, индексами, вариантами и автоблоками. | DirectiveExecutor |
| ExecutionSnapshot | Представление текущего состояния исполнения, передаваемое GUI. | Преобразование кадра |
| RequestId | Идентификатор запроса для связи ответа с ожидающей операцией. Сам по себе не устанавливает формат внешнего протокола. | Генератор · Привязка к директиве |
| Принадлежность потоку Qt | Поток, с которым связан объект QObject. Для исполнителя связь назначается при moveToThread(). | Композиция |
