# Бэклог ИСР

Исходная база — первичный онбординг ветки rewrite на 6a7da4fbe7ee291e6be41cde870763ec5abc135e. Категория записи описывает тип наблюдения. Приоритеты и сроки пока не назначены. Все записи предварительные. Разработчик решает, какие из них оформлять отдельными карточками.

Статусы карточек: draft → clarified → planned → implementing → review → done. Переход в done подтверждает разработчик после проверки. Шаблон карточки

## Подтверждённые дефекты

По итогам онбординга подтверждённых дефектов нет. Для добавления записи нужны согласованное ожидаемое поведение, свидетельство отклонения и указание обследованной версии. Заглушки и незавершённые компоненты сами по себе отражают стадию разработки.

| WIP-04 | draft | По наблюдению разработчика, при выводе прочитанных директив в таблицу теряется часть оформления исходного файла, в том числе пустые строки и метки НШС. По его сообщению, Windows-версия показывает между директивами столько пустых строк, сколько есть в файле, в том числе ни одной. | Для читаемости разработчик выбрал добавлять пустую строку между соседними директивами на Astra, если в файле разделителя нет. Рабочая идея для НШС — показывать начальную метку перед первой директивой блока и конечную после последней, используя имя и индексы директив блока из уже передаваемого в интерфейс `SectionStruct`. Двойной щелчок по метке не должен запускать директиву. В текущем коде обработчик уже пропускает строки с `directive_index`, равным `ProgramRow::NoDirectiveIndex`. Открыты правила для уже имеющихся пустых строк и для блоков без директив, если они допустимы. |

По WIP-04 разработчик сравнивает добавление строк при подготовке таблицы с изменением структуры раздела, чтобы она явно хранила строки для показа. Он указал, что добавление строк внутрь самих директив может затронуть их проверку, а более широкая переделка формата данных может затронуть исполнитель и интерфейс. Точечное чтение кода подтвердило, что проверка директивы «Команда» читает первую строку, а исполнитель и таблица используют текущие данные директив. Выбор варианта и объём правок остаются открытыми. [Проверка команды](../Services/Directives/commanddirective.cpp#L45) · [Исполнитель](../Services/DirectiveExecutor/directiveexecutor.cpp#L489) · [Подготовка таблицы](../Services/GUI/ProgViewWgt/programviewwidget.cpp#L73)
